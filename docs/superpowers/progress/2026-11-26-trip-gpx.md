# Dziennik eksportu GPX

- Dodano lokalny eksport GPX 1.1 zapisanych tras GPS, przycisk obok JSON, ostrzeżenie o dokładnej lokalizacji i widoczne błędy. Wykorzystano istniejącą walidację, segmentację i udostępnianie plików.
- Zaobserwowano RED → GREEN dla brakującego eksportu, walidacji, kodowania XML i poprawnego zapisu współrzędnych. Siedem testów GPX przechodzi, w tym rzeczywiste parsowanie przez `xmllint`; test przerw sprawdza również istniejącą segmentację.
- Node 24.18.0: pełne `npm test` przechodzi (133 testy), `npm run lint` przechodzi. Pierwszy przebieg w sandboxie zablokował 11 istniejących testów przez `listen EPERM`; ponowny przebieg z dostępem do localhost przeszedł.
- `npm run typecheck` i `npm run lint` przeszły po integracji; końcowy zestaw regresji obejmuje 161 testów bez błędów. Niezależny przegląd GPX nie wykazał problemów.
- Nie wykonano natywnego buildu ani testu systemowego arkusza udostępniania na urządzeniu. Nie dodano danych pokazowych.

Źródło: [oficjalny schemat GPX 1.1](https://www.topografix.com/GPX/1/1/) (`gpxType`, `trkType`, `trksegType`, `wptType`).
