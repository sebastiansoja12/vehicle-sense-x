# GPX-Exportprotokoll

- Lokalen GPX-1.1-Export gespeicherter GPS-Fahrten, eine Schaltfläche neben JSON, einen Hinweis auf genaue Standorte und sichtbare Fehler ergänzt. Vorhandene Validierung, Segmentierung und Dateifreigabe wiederverwendet.
- RED → GREEN für fehlenden Export, Validierung, XML-Kodierung und Koordinatenausgabe beobachtet. Sieben GPX-Tests bestehen, einschließlich tatsächlicher XML-Analyse mit `xmllint`; der Lückentest prüft auch die vorhandene Segmentierung.
- Node 24.18.0: vollständiges `npm test` besteht (133 Tests), `npm run lint` besteht. Der erste Sandbox-Lauf blockierte elf vorhandene Tests mit `listen EPERM`; die Wiederholung mit localhost-Zugriff bestand.
- `npm run typecheck` und `npm run lint` bestanden nach der Integration; die abschließende Regression umfasst 161 erfolgreiche Tests. Die unabhängige GPX-Prüfung fand keine Probleme.
- Keine nativen Builds und kein Test des Systemdialogs zum Teilen auf einem Gerät. Keine Demodaten ergänzt.

Quelle: [offizielles GPX-1.1-Schema](https://www.topografix.com/GPX/1/1/) (`gpxType`, `trkType`, `trksegType`, `wptType`).
