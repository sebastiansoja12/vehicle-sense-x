# Wstępna kontrola konfiguracji wydania

- Expo Doctor początkowo zaliczył 18/20 sprawdzeń i wskazał brakujący bezpośredni moduł równorzędny expo-font oraz oznaczenie Classic/TCP w metadanych Directory jako nieprzetestowanych na New Architecture. Dodano oficjalny expo-font zgodny z SDK przez Expo CLI; zero ustaleń npm audit. Nie dodano wykluczeń ostrzeżeń.
- Wygenerowano oba projekty natywne przez Expo prebuild --no-install w odizolowanej kopii tymczasowej. Ujawniło to brak zależności expo-system-ui dla skonfigurowanego jasnego wyglądu Androida; dodano oficjalny pakiet zgodny z SDK, zero ustaleń npm audit.
- Dodano papierowe tło widoku głównego i usunięto nieużywane uprawnienie nakładki Androida przez konfigurację aplikacji. Ponowne generowanie konfiguracji zakończyło się powodzeniem, bez dodawania/edytowania projektów natywnych w repozytorium.
- Sprawdzono rzeczywiście wygenerowane Info.plist, AndroidManifest, zasoby stylów Androida i właściwości budowania. Asercje przeszły dla lokalizacji wyłącznie przy otwartej aplikacji, opisów Bluetooth/sieci lokalnej/zdjęć, braku kamery/mikrofonu/lokalizacji Always/trybów tła, wyłączonej kopii aplikacji Android, zablokowanych szerokich uprawnień mediów/nakładki i jasnego interfejsu. Scalanie manifestów bibliotek, kompilacja natywna i zawartość podpisanych plików binarnych pozostają niezweryfikowane. Wybrane rzeczywiste wartości zachowano w docs/verification/2026-11-25-native-config.json.
- Naprawiono traktowanie ośmiocyfrowego SIG UUID (0000180D) jako niestandardowego przez wykrywanie BLE. Nowy test regresji nie przeszedł przed poprawką normalizacji, a przeszedł po niej, także z rzeczywistą niestandardową usługą obok czujnika i ośmiocyfrowym niestandardowym UUID. Nie dodano do aplikacji urządzenia demonstracyjnego ani pomiarów.
- Końcowy zestaw: 135 testów przeszło (121 mobile, 10 serwera, 4 prototypu). Końcowe zadania typów/lint/eksportu/Doctor zapisano wynikami poniżej; sprawdzenia te nie są ogólną deklaracją gotowości produkcyjnej.
- Wyniki końcowe: TypeScript i lint kod 0; eksport JS/Hermes web/iOS/Android kod 0; katalog --check odtwarza oba artefakty; audyt przy instalacji npm zgłasza zero podatności. Expo Doctor kod 1 z 19/20 zaliczonymi sprawdzeniami, wyłącznie z powodu jawnie zachowanego ostrzeżenia metadanych New Architecture dla Classic/TCP.
