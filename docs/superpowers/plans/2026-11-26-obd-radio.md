# Połączenie OBD i radio Bluetooth — plan wdrożenia

> Dla wykonawcy: użyj superpowers:executing-plans do pracy w tej sesji.

**Projekt:** [Projekt](../specs/2026-11-26-obd-radio.md)

**Cel i architektura:** Cel: rzeczywiste odczyty ELM327 przez BLE, Android SPP i Wi-Fi; radio służy jako wyjście dźwięku telefonu. Zwykłe radio A2DP/HFP nie jest adapterem diagnostycznym.

**Stos technologiczny:** Expo 58, React Native 0.88, TypeScript, Node 24, ELM327, expo-speech.

## Ograniczenia wspólne

Założenie: telefon przesyła dźwięk do radia. Pytanie o radio z Androidem pozostaje otwarte. Bez fizycznego sprzętu wynik testów nie potwierdza zgodności wszystkich adapterów ani równoczesnego działania profili Bluetooth.

## Zakres przeglądu

Ogranicz komunikat startowy BLE do 8192 znaków ASCII przed pierwszym poleceniem. Rozłączenie unieważnia sesję. Kasowanie wymaga nowego pełnego raportu po pomiarze Live Data.
