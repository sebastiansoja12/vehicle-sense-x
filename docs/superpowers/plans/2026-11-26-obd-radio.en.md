# OBD connection and Bluetooth radio implementation plan

> For agentic workers: use superpowers:executing-plans for inline execution.

**Design:** [Design](../specs/2026-11-26-obd-radio.en.md)

**Goal and architecture:** Goal: real ELM327 readings over BLE, Android SPP and Wi-Fi; the radio serves as the phone audio output. An ordinary A2DP/HFP radio is not a diagnostic adapter.

**Tech stack:** Expo 58, React Native 0.88, TypeScript, Node 24, ELM327, expo-speech.

## Global constraints

Assumption: the phone sends audio to the radio. The question about Android head units remains open. Without physical hardware, tests cannot confirm every adapter or simultaneous Bluetooth profile operation.

## Review focus

Bound the BLE startup banner to 8192 ASCII characters before the first command. Disconnection invalidates the session. Clearing requires a new full report after a Live Data measurement.
