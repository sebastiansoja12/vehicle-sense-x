# Local OBD VIN Implementation Plan

> Use superpowers:executing-plans inline, with the existing continuous-execution authorization.

**Goal:** read VIN from the selected standard CAN ECU and save it to the garage only after a preview and confirmation.
**Architecture:** strict mode 09 PID 02 decoder; driver method using the selected CAN address; immutable domain update with a stale-value guard; optional source evidence retained in storage.
**Sources:** ELM327DSK pp. 43–45: CAN VIN payload `49 02 01` followed by exactly 17 ASCII VIN characters. This reads ECU data, not a manufacturer database verification or a VIN specification decoder.
