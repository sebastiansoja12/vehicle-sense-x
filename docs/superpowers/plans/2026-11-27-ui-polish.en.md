# Interface polish

Goal: consistent, readable UI on phones and computers. Preserve the light identity, red accent, actual data and all existing actions. The user requested work without questions and publishing to main.

Approach: improve shared components instead of adding a UI library or separate web app. Add a sidebar only on wide web, using the same breakpoint to hide bottom tabs. Keep phone tabs and system safe spacing. Home: vehicle profile, quick actions, monthly summary, diagnostics, reminders and additional modules. Never generate photos pretending to be the owner’s vehicle or demonstration data.

Files: navigation model and test; shared shell; theme and components; vehicle profile and extracted Home; Router layouts; accessory cards. First test active routes and layout breakpoint, then implement. Check phone, narrow screen, desktop, form, empty states and filters; then types, lint, suite, documentation and exports. Garage data and financial/OBD logic stay outside the change.
